# パフォーマンスチューニング ＆ キャッシュ戦略 Skill

本スキルは、アプリケーションのレスポンス向上とデータストアの負荷軽減を両立させるため、**クエリ最適化、複合インデックス設計、インメモリTTLキャッシュ** を導入・保守するための標準プロトコルを定義します。

---

## ⚡ 3 大パフォーマンス最適化原則

1. **不要クエリの削減（キャッシュ戦略）:**
   - 変更頻度の低いマスターデータや集計データは、適切な TTL（Time-To-Live）を持つインメモリキャッシュまたはキャッシュテーブルを活用する。
2. **インデックス設計の最適化:**
   - 頻繁にフィルタリング（`WHERE`）やソート（`ORDER BY`）、結合（`JOIN`）に使用されるカラムに適切なインデックスを付与する。
3. **不要な全件取得の排除:**
   - メモリを圧迫する全件ロードを避け、ページネーションやチャンク処理（カーソル）を活用する。
