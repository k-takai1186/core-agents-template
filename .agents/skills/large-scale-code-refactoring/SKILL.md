# 大規模コードリファクタリング Skill

本スキルは、肥大化した単一モジュール（巨大ファイル）を複数の関心事・責務ごとに安全に分割・再構築する際、**既存の呼び出し元コードを一切破壊せず（後方互換性 100% 維持）、型安全とテスト通過を保証しながら完了させる** ための標準プロトコルを定めます。

---

## 🏗️ リファクタリング 4 原則

1. **ファサードパターンの徹底:**
   - 分割元のモジュールは廃止せず、分割先モジュール群からの再エクスポート窓口（Facade）として維持する。
2. **依存関係の単方向化:**
   - モジュール間の循環参照（Circular Dependency）を排除し、依存グラフをクリーンな階層構造にする。
3. **段階的移行:**
   - 一度にすべてを書き換えず、サブモジュール単位で切り出しとテストを繰り返す。
4. **DoD による回帰テスト:**
   - リファクタリング前後で既存ユニットテストが 1 件も失敗しないことを機械的に保証する。
