# 実装・リファクタリングスキル (Implementation & Refactoring Skill)

本スキルは、実装およびリファクタリングフェーズにおいて、保守性・テスタビリティ・安全性を極大化するためのプロトコルを定めます。

---

## 🛠️ 実装 4 大規約

1. **DRY原則（Don't Repeat Yourself）の徹底:**
   - 同一のクエリやビジネスロジックを複数箇所に重複させず、データアクセス層や共通ユーティリティに一本化する。
2. **標準ロガーの使用:**
   - `print()` や `console.log()` を廃止し、言語標準の構造化ロガーを使用してログレベルを適切に設定する。
3. **機密情報の環境変数化:**
   - 接続パスワード、API キー等は設定ファイルやコードに埋め込まず、環境変数（`.env`）から取得する。
4. **リソース管理の徹底:**
   - データベース接続、ファイルハンドル、HTTP セッションはコンテキストマネージャや `try-finally` で確実にクローズする。
