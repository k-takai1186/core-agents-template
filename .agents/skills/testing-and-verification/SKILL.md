# テスト・動作検証スキル (Testing & Verification Skill)

本スキルは、コードの改修や機能追加を行った際、主観的・目視による確認を排除し、**決定論的な自動テスト・ビルド・検証** を実行して品質を保証するための手順を定めます。

---

## 🧪 検証プロトコル

1. **ユニットテスト (Unit Tests):**
   - 外部依存（DB、外部API、ファイルシステム）は適切にモック化し、高速かつ安定して成功するテストを作成・実行する。
2. **結合テスト ＆ 異常系テスト:**
   - 接続タイムアウト、不正データ入力、空データ時の動作を網羅する。
3. **静的解析 ＆ 型検査:**
   - リンターや型チェッカーによるエラー 0 件を確認する。
4. **ビルド検証:**
   - プロダクションビルドを実行し、トランスパイルやアセットバンドルが成功することを確認する。
