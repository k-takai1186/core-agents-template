# リリース前レビュー実行スキル (Release Review Skill)

本スキルは、新しいバージョン（タグ）を切る前、または本番環境へデプロイする前に、システムの品質・セキュリティ・耐障害性が基準を満たしているかを網羅的に検証するためのチェックリストと手順を定義します。

---

## 📋 リリース前 5 大チェックリスト

1. **セキュリティ ＆ 機密情報:**
   - 秘密鍵、パスワード、接続文字列がリポジトリ内にコミットされていないか。
2. **耐障害性 ＆ エラーハンドリング:**
   - DB 接続断、タイムアウト、不正データ入力時に適切なエラーログが出力され、プロセスが安全に停止/リカバリするか。
3. **パフォーマンス ＆ リソースリーク:**
   - コネクションリーク、メモリリーク、不要な全件フェッチが存在しないか。
4. **ドキュメント ＆ 引き継ぎ書:**
   - `docs/CONTEXT_HANDOFF.md` やリリースノートが最新の状態に更新されているか。
5. **DoD 全ゲート通過:**
   - 静的型検査、自動テスト、ビルド、環境診断の終了コードがすべて 0 であること。
